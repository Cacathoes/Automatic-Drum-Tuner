## **OBJECTIFS**

## **CONTENUS ATTENDUS**

- Créer un système pour **_accorder automatiquement_** le fût d’une batterie.
  
- Avoir un système complètement **_open source_**.

- Un **_accordeur_** de batterie **_automatique_**.

Garder une trace de notre projet dans un **_dépôt GitHub_** avec le code et les explications

## **CONTRAINTES & ATTENTES**

- **_Limite de temps :_** De Novembre 2026 à Mai 2027 pour les Olympiades.

- **_Respect du budget :_** Ne pas dépasser l'enveloppe de **_75 € TTC_** , en privilégiant la récupération et les outils disponibles au lycée.

- **_Précision et Plage d'accordage :_** Le système doit être capable de détecter des fréquences précises correspondantes aux notes de musique standard des fûts de batterie, avec une marge d'erreur minimale.

- **_Couple et Puissance :_** Les moteurs doivent fournir un couple suffisant pour viser et tendre la peau, tout en étant assez compacts.

- **_Alimentation et Autonomie :_** Le système doit être alimenté sur batterie (rechargeable par USB-C) pour être facilement transportable.

- **_Compatibilité Mécanique :_** Le système de fixation doit s'adapter à différents diamètres de fûts et à un nombre variable de tirants.

- **_Simplicité d'utilisation :_** L'interface doit être intuitive pour que même un novice puisse lancer un accordage sans compétences techniques.

- **_Transparence et Licence :_** Le code source et les fichiers de conception doivent être publiés sur un dépôt GitHub sous une licence open source (GPL).

- **_Documentation :_** Le dépôt GitHub doit inclure un fichier README.md complet expliquant l'installation, le câblage et le mode d'emploi du système.
